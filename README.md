# Локальное приложение сверки актов · Qwen3-VL-4B-Instruct

Основной интерфейс — обычное окно Windows (`desktop.py`, Tkinter). PDF со сканами читает **Qwen/Qwen3-VL-4B-Instruct из локальной папки весов**. Браузер, облачный OCR и сервер не требуются. Excel и сверка обрабатываются на ноутбуке.

## Ваш ноутбук: Windows 11, RTX 3050 Laptop 4 ГБ, ОЗУ 16 ГБ

Выбирайте устройство **auto**. Веса в FP16 занимают около 8 ГБ без учета изображений, контекста и рабочих буферов, поэтому полностью на GPU не помещаются. Программа ограничивает размещение весов на GPU, оставляет запас для вычислений и переносит остальные веса в ОЗУ; при необходимости Accelerate использует временный каталог дискового offload. Для этого конфигурация использует FP16, а не квантование. Закройте тяжелые приложения, оставьте свободное место на SSD. Скорость и достаточность памяти на вашем ноутбуке еще не проверены; крупные страницы могут приводить к нехватке памяти.

Режим `cuda` означает размещение всех весов на GPU и для 4 ГБ не подходит. CPU использует FP32 и требует около 16 ГБ только для весов, поэтому **CPU-режим не рекомендуется при 16 ГБ ОЗУ**. GGUF и 4-битное квантование эта версия не поддерживает.

## Установка Windows

Установите 64-битный Python 3.12 с python.org (включая Tcl/Tk) и актуальный драйвер NVIDIA. Распакуйте проект в папку. В PowerShell из этой папки:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.9.0 torchvision==0.24.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe -c "import torch; print('CUDA:', torch.cuda.is_available())"
```

Если проверка выводит `CUDA: False`, проверьте драйвер и установку PyTorch по официальной инструкции https://pytorch.org/get-started/locally/ — не запускайте тяжелую модель на CPU с 16 ГБ ОЗУ.

Один раз загрузите официальные веса (потребуется Интернет и несколько ГБ свободного места):

```powershell
.\.venv\Scripts\python.exe download-model.py
```

Если веса уже скачаны, этот шаг не нужен. Нужна полная папка Hugging Face с `config.json`, файлами процессора/токенизатора, индексом и всеми частями `.safetensors`; один файл GGUF не подойдет. Приложение загружает только локальные файлы с `local_files_only=True` и не выполняет удаленный код модели.

Запустите двойным щелчком **start-local.bat**. Это запуск исходного Python-приложения, не автономный установщик `.exe`.

## Работа

1. Выберите папку `models/Qwen3-VL-4B-Instruct`, PDF контрагента и наш `.xlsx`.
2. Оставьте устройство `auto`, нажмите «Распознать PDF через Qwen». Первая загрузка весов может занять время. Интерфейс не блокируется, страницы обрабатываются последовательно.
3. Нажмите «Загрузить Excel»: выберите лист, строку заголовков и колонки. Для суммы со знаком оставьте кредит пустым; для отдельных колонок используйте дебет и кредит (сумма = дебет минус кредит).
4. Проверьте обе таблицы и вкладку ответа модели. Двойной щелчок редактирует ячейку. Удалите остатки и итоги, добавьте пропущенные операции. Модель может ошибаться и выбирать неправильную сторону таблицы. При зеркальном дебете/кредите поменяйте знак сумм контрагента.
5. Подтвердите проверку и сохраните отчет Excel. Номер документа, сумма и дата используются для сопоставления. Дубликаты не считаются совпадениями автоматически; разница дат отмечается отдельно. Строки без номера документа требуют ручной проверки.

Модель извлекает данные; арифметика и сопоставление выполняются обычным кодом. Некорректный или оборванный JSON останавливает распознавание, неизвестные суммы не заменяются нулем. Сальдо отдельно не сверяется. Формат `.xls` предварительно сохраните как `.xlsx`. Поддерживаются PDF до 100 страниц без пароля. Файлы не отправляются в Интернет; при работе модель не скачивается. Временные файлы offload весов могут остаться в системной временной папке.

## Проверки и ограничения

Проверены разбор ответов модели, расчет дебет минус кредит, сохранение ведущих нулей, отклонение некорректных ответов, сверка и Excel-экспорт. **Реальная генерация Qwen и GUI на Windows пока не проверены**: в облачной среде нет GPU, весов и графического дисплея. Для окончательной проверки запустите программу на ноутбуке с вашими PDF и Excel.

```powershell
.\.venv\Scripts\python.exe -m unittest test_qwen test_reconcile.ReconciliationTests.test_amounts_and_missing test_reconcile.ReconciliationTests.test_duplicates_not_silently_matched test_reconcile.ReconciliationTests.test_dates_signs_and_invalid test_reconcile.ReconciliationTests.test_report_formula_safety -v
```

`app.py` — прежний необязательный веб-прототип с Tesseract; для нового настольного приложения он не используется. `requirements.lock` и `scripts/setup.sh` относятся к этому старому прототипу. `test_real_scan_ocr` также проверяет старый Tesseract, а не Qwen.
